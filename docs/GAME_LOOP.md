# Game loop por capítulo (v0.4)

## Bucle general
**Mapa de Zaryab (hub)** → elegir misión (principal ★, secundaria, personal, facción o moral) o recorrer un distrito (Oráculo) → **escena** (diálogos, elecciones con pruebas de habilidad CD) → **combate táctico** en cuadrícula isométrica (turnos, acciones 5e, terreno destructible, jefes con mecánicas) → **resultado** (XP, botín, PF, heridos) → **santuario** (seguidores, rituales, edificios, milagros, inventario, tienda, taller) → **subir de nivel** (rasgos 5e y evolución de arquetipo) → el tiempo avanza (Alerta del Conclave, reloj de eventos).

## Misiones opcionales que sostienen el ritmo
- **Personales** (Acto I): una por personaje, que abren los arcos.
- **Morales** (13): niño y escorpión, ladrón, djinn esclavizado, inquisidor, Marid, juicio del pueblo, Jann, etc. Cada una deja **ecos** que estallan días después.
- **El Inventario de Maunator** (tras el Cap. VIII): robo en un sótano rotante con alerta, cinco capítulos propios.
- **Tigre alado** y **cementerio** (tras el Cap. VI): jefes opcionales y compañeros.
